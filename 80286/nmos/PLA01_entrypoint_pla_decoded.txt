NMOS 80286 PLA match decoder (split into two banks, A and B)

Guilty Parties:
        Daniel Balsom (GloriousCow)

264 columns: 
        Bank A: 132 active
        Bank B: 108 active (24 unused)

MATCH:  the same 12 normalized input bits, in original source-row order.
        ? = unconstrained. Row-pair logic accounts for each input's polarity.
        OP7/OP5/OP3/OP1: first row connected matches 1; second row connected matches 0.
        OP6/OP4/OP2/OP0: first row connected matches 0; second row connected matches 1.
       
        Opcode pass:   0 E !REP PE OP7 OP6 OP5 OP4 OP3 OP2 OP1 OP0
        Feedback pass: 1 E !S0   M S5  S4  R2  R1  R0  S3  S2  S1
       
        REP = repeat prefix
        PE = protected mode.

        E = 0F escape
        S = six-bit feedback selector
        M = 0 register (mod=11), 1 memory
        R = ModR/M `reg` field

        ! means inverted.

OR:     11 connection bits, original output rows top-to-bottom, read left-to-right.
uADDR:  Microcode address contribution, in hexadecimal.
SEL:    Feedback selector contribution, in hexadecimal.

        Both read OR top-to-bottom as binary, with no inversion; -- = not applicable.
        Both columns are filled when a term serves both roles for different opcodes.
        
        OR all simultaneously matching terms BEFORE interpreting the result.

        "combined" lists resulting values where this term alone is insufficient;
        its u: and s: prefixes identify microcode addresses and selectors, respectively.

        F6/F7 s:016/s:017 feed the ModR/M pass; they are not routine addresses.

OPCODES / MODRM: 
        Opcode bytes are in hexadecimal; ranges are inclusive.

        0F 08-0F means 0F 08 through 0F 0F (the prefix applies to the entire range).
        /n or /n-m restricts ModR/M.reg for ALL opcodes listed in that row.
        No / suffix on a feedback row means all eight reg-field values match.
        
        Unused columns have no connected outputs and no opcode assignment.

Instruction names describe matched encodings, including reserved/undocumented cases.
126 of 127 feedback terms have opcode assignments; B071 remains unresolved.

Selector 000 is valid even without an active output term (e.g. ADD r/m,r).
